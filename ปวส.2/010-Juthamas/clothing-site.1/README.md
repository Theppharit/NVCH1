# THREADY (เว็บร้านเสื้อผ้าแบบ Static)

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

```
clothing-site/
├── index.html          โครงหน้า HTML
├── css/
│   ├── base.css        สี ฟอนต์ รีเซ็ต (เปลี่ยนสีแบรนด์ที่ --brand)
│   ├── layout.css      header / section / grid / footer
│   └── components.css  ปุ่ม แบนเนอร์ หมวดหมู่ การ์ดสินค้า สไลเดอร์
├── js/
│   ├── data.js         ข้อมูลสินค้า/แบนเนอร์/หมวดหมู่ตัวอย่าง (แก้ตรงนี้)
│   └── main.js         สร้างเนื้อหา แบนเนอร์เลื่อน กรองหมวด ค้นหา ตะกร้า
└── assets/images/      ใส่รูปสินค้า/โลโก้ (ระบุ path ใน data.js ที่ช่อง image)
```

ชื่อร้าน สินค้า และราคาเป็นข้อมูลจำลอง เปลี่ยนเป็นของจริงได้ที่ `js/data.js`
