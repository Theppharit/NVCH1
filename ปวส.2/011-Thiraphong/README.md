# Hangar Game Store

ร้านเกมตัวอย่าง (HTML + CSS + JavaScript ล้วน ไม่ต้องติดตั้งอะไรเพิ่ม)

## โครงสร้าง
- `index.html` – โครงหน้าเว็บ
- `css/style.css` – สี ฟอนต์ เลย์เอาต์ (สีอยู่ใน `:root` ด้านบนสุด)
- `js/data.js` – ข้อมูลเกม (`GAMES`), เกมแนะนำ (`FEATURED`), แนวเกม (`GENRES`)
- `js/app.js` – การทำงาน: ค้นหา ตัวกรอง ตะกร้า รายการที่อยากได้ คลังเกม
- `assets/` – โลโก้ และไว้วางรูปปกเกม

## วิธีเปิด
เปิด `index.html` ในเบราว์เซอร์ หรือใน VS Code ใช้ส่วนขยาย Live Server
