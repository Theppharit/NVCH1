# PLAYNEST — เว็บรวมเกมฟรี

โปรเจกต์หน้าเว็บรวมเกมจากไฟล์ HTML ที่ผู้ใช้ส่งมา ปรับโครงสร้างใหม่เป็น HTML / CSS / JavaScript แยกไฟล์ และเพิ่มเกมจากโปรเจกต์โอเพนซอร์ส

## วิธีเปิดใช้งาน

1. แตกไฟล์ ZIP
2. เปิด `index.html` ด้วย Chrome, Edge หรือ Firefox
3. เกมที่อยู่ในหมวด “เล่นในเว็บนี้” เล่นได้ทันที ส่วนเกมที่มีป้าย `OPEN SOURCE` จะโหลดผ่านอินเทอร์เน็ตจาก jsDelivr/GitHub

แนะนำให้ใช้ Live Server หรือเปิดเซิร์ฟเวอร์แบบง่ายเพื่อทดสอบ:

```bash
python -m http.server 8000
```

จากนั้นเปิด `http://localhost:8000`

## ส่วนประกอบ

- `index.html` — โครงหน้าเว็บและรายการแหล่งที่มา
- `css/style.css` — รูปแบบหน้าเว็บ รองรับมือถือและคอมพิวเตอร์
- `js/app.js` — ระบบค้นหา หมวดหมู่ รายการโปรด หน้าต่างเล่นเกม และมินิเกมในเว็บ
- `LICENSES.md` — รายละเอียดแหล่งที่มาและสัญญาอนุญาต

## เกมที่มีในเว็บ

**มินิเกมในเว็บนี้ (6 เกม):** Snake Classic, 2048 Puzzle, Memory Match, Tic Tac Toe, Flappy Flyer และ Whack-a-Mole

**เกมภายนอก (12 เกม):** Block Stack, Maze Chomp, Minesweeper, Breakout, Pong, Sudoku, Word Hunt, Connect Four, Doodle Jump, Geometry Dash, Neon Slope และ PolyTrack

เกมภายนอกฝังจากไฟล์ HTML5 ของโปรเจกต์ Arcadia ผ่าน jsDelivr โดยไม่ได้คัดลอกไฟล์เกมเข้ามาใน ZIP หาก CDN หรือผู้ให้บริการไม่พร้อมใช้งาน เกมนั้นอาจไม่โหลด สามารถกด “เปิดเกมในแท็บใหม่” ในหน้าต่างเล่นเกมได้

## การแก้ไขรายการเกม

แก้ไขอาร์เรย์ `games` ใน `js/app.js` เพื่อเพิ่มหรือลบเกม หากเป็นเกมภายนอก ให้ระบุ `src` เป็นโฟลเดอร์เกมที่มีอยู่ในโปรเจกต์ต้นทาง และตรวจสอบใบอนุญาตก่อนนำเกมอื่นมาเพิ่ม
