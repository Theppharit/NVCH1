# kroowit-website

เว็บไซต์ HTML/CSS/JS ล้วน (ไม่ต้องติดตั้งอะไรเพิ่ม)

## เปิดใน VS Code
1. แตก zip แล้วเลือก File > Open Folder... เปิดโฟลเดอร์ `kroowit-website`
2. ติดตั้งส่วนขยาย **Live Server** (Ritwick Dey)
3. คลิกขวาที่ `index.html` > Open with Live Server

## โครงสร้าง
- `index.html` โครงหน้าและเนื้อหา
- `css/style.css` สีและตัวอักษร (ปรับสีที่ `:root` บนสุดของไฟล์)
- `js/main.js` เมนูมือถือ เมนูย่อย กล่องอธิบายส่วนประกอบเว็บ และสารบัญ
- `images/` ใส่รูปโลโก้หรือภาพประกอบ

## เพิ่มหน้าใหม่
คัดลอก `index.html` เป็นไฟล์ใหม่ เช่น `principles.html` แก้ส่วน `<main>` แล้วเปลี่ยนลิงก์ "ถัดไป" ให้ชี้มาที่ไฟล์นั้น

หมายเหตุ: ฟอนต์ (Prompt, Sarabun) โหลดจาก Google Fonts ต้องต่ออินเทอร์เน็ต
