หน่วยการเรียนรู้ที่ 1

ความรู้เบื้องต้นเกี่ยวกับเว็บไซต์

หน้าเว็บหนึ่งหน้าแบ่งเป็น 3 ส่วนหลัก ลองคลิกแต่ละส่วนในหน้าต่างเบราว์เซอร์ เพื่อดูว่าทำหน้าที่อะไร

ส่วนหัวของหน้า (Page Header)

อยู่บนสุดของหน้า มักมีโลโก้ ชื่อเว็บไซต์ และเมนูหลัก (Navigation Bar) ที่พาไปยังเนื้อหาส่วนอื่น โลโก้ช่วยให้เว็บดูน่าเชื่อถือ

ส่วนเนื้อหา (Page Body)

อยู่กลางหน้า แสดงข้อความ ตาราง ภาพ และวิดีโอ ควรวางหัวเรื่องสำคัญไว้บนสุด ใช้ตัวอักษรอ่านง่าย และจัดวางให้เป็นระเบียบ

ส่วนท้ายของหน้า (Page Footer)

มีหรือไม่มีก็ได้ ใช้ใส่ข้อมูลเสริม เช่น ที่อยู่ เบอร์โทร แผนที่ ข้อความลิขสิทธิ์ และคำแนะนำการใช้เว็บไซต์

https://www.example.com

ในบทเรียนนี้

ส่วนประกอบของหน้าเว็บ เว็บไซต์คืออะไร เว็บเบราว์เซอร์ โฮมเพจและเว็บเพจ Static และ Dynamic 9 ประเภทของเว็บไซต์

เว็บไซต์คืออะไร

เว็บไซต์ (Website) คือกลุ่มของเว็บเพจที่เชื่อมถึงกันด้วยไฮเปอร์ลิงก์ ใช้นำเสนอข้อมูลผ่านคอมพิวเตอร์และอินเทอร์เน็ต เปิดดูได้ด้วยเว็บเบราว์เซอร์ และเก็บอยู่บนเวิลด์ไวด์เว็บ (WWW)

URL
ที่อยู่เต็มของหน้าเว็บหน้าใดหน้าหนึ่ง
Domain Name
ชื่อเว็บไซต์ที่จำง่าย ใช้แทน IP Address ถ้าเจ้าของเว็บเปลี่ยน IP ผู้ใช้ก็ยังเข้าด้วยชื่อเดิมได้
IP Address
หมายเลขประจำเครื่องเซิร์ฟเวอร์ ตัวเลขจำยาก จึงมี Domain Name มาช่วย
Hosting
พื้นที่บนเครื่องแม่ข่ายที่ผู้ให้บริการเปิดให้เช่า เป็นรายเดือนหรือรายปี
Internet
ตัวกลางที่เชื่อมให้คนท่องเว็บได้ และให้องค์กรเผยแพร่ข้อมูลของตัวเอง
Web Service
บริการที่ดึงข้อมูลจากเว็บหนึ่งไปแสดงบนอีกเว็บหนึ่ง

เว็บเบราว์เซอร์

โปรแกรมสำหรับท่องเว็บ อ่านภาษา HTML แล้วแสดงผลเป็นข้อความ ภาพ และมัลติมีเดีย เบราว์เซอร์ที่รองรับ HTML5 และ CSS3 ซึ่งเป็นที่นิยม ได้แก่

  • Internet Explorer
  • Mozilla Firefox
  • Google Chrome
  • Safari

โฮมเพจและเว็บเพจ

โฮมเพจ (Home Page) คือหน้าแรกของเว็บไซต์ รวมเมนูและเรื่องราวสำคัญไว้ ถ้าออกแบบสวยและเป็นระเบียบ คนจะอยากเข้าชมต่อ

เว็บเพจ (Web Page) คือหน้าเอกสาร HTML แต่ละหน้า นำเสนอเรื่องราวทีละหน้า และคลิกลิงก์ไปหน้าอื่นได้

เว็บ Static และเว็บ Dynamic

StaticDynamic
การโต้ตอบแสดงข้อมูลอย่างเดียว ไม่รับส่งข้อมูลกับผู้เข้าชมรับส่งข้อมูลกับผู้เข้าชมได้
ตัวอย่างแกลเลอรีภาพ เว็บบริษัทหรือองค์กร เว็บให้ความรู้เว็บบอร์ด โซเชียลมีเดีย เว็บสมัครสมาชิก เว็บขายของที่แชทกับผู้ขายได้

9 ประเภทของเว็บไซต์

Personal
เว็บส่วนตัว คล้ายสมุดไดอารี่ เล่าเรื่อง ประสบการณ์ และแสดงผลงานของเจ้าของ
E-Commerce
เว็บซื้อขายสินค้า มีรายละเอียด รูปภาพ และจ่ายเงินได้ในเว็บ เช่น Pomelo, Uniqlo, Adidas
Business
เว็บธุรกิจ ประชาสัมพันธ์ แนะนำสินค้าหรือบริการและจุดเด่น เช่น HubSpot, Zapier
Blog
เว็บบทความที่เรียงตามเวลา มักใช้ CMS จัดการเนื้อหาโดยไม่ต้องเขียนโค้ด เช่น Medium, TED Blog
Portfolio
เว็บรวมแฟ้มสะสมผลงาน ใช้สมัครงานได้ เช่น Behance
Membership
ต้องสมัครสมาชิกก่อนจึงดูเนื้อหาได้ เช่น Netflix, Disney+ Hotstar
Non-profit
เว็บของหน่วยงาน มูลนิธิ หรือสมาคมที่ไม่หวังกำไร ทำงานเพื่อสังคม เช่น UNICEF
Information
เว็บให้ข้อมูลความรู้ ค้นหาตามคำสำคัญได้ เช่น Wikipedia
Online Forum
ชุมชนออนไลน์ที่พูดคุยกันตามความสนใจ เช่น Pantip, Dek-d, Reddit
ก่อนหน้าแบบทดสอบก่อนเรียน ถัดไปหลักการออกแบบเว็บไซต์
